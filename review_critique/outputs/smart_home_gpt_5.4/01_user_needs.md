## Business Analysis & Requirements Specification

### 1. Discovered User Needs

| id | User Group Type | User Group | demand | User Journey |
|---|---|---|---|---|
| UN-001 | Primary | General User | High | A resident accesses the DigitalHome personal web page, logs in, reviews home environment status, and issues control actions to manage temperature, humidity, security, appliances, and lighting in the home. |
| UN-002 | Primary | Master User | High | A designated master user accesses privileged functions to configure the DigitalHome system, manage user accounts, adjust default parameter settings, and exercise the same operational rights as the DH Technician while also using all general-user capabilities. |
| UN-003 | Secondary | DH Technician | High | A trained technician sets up, maintains, starts, stops, and reconfigures the DigitalHome system, including system parameters and user account establishment, using higher-privilege administration capabilities. |
| UN-004 | Overarching | HomeOwner Management / Product Stakeholders | High | Management evaluates the prototype in a realistic simulated environment, delivered under defined project constraints and governance controls, to support business decisions about future DigitalHome commercialization and product direction. |
| UN-005 | Overarching | All DigitalHome Users | Medium | Users interact with the system through a web-based interface on the DigitalHome web server or local home server using common web operations such as login, logout, browsing, and request submission. |
| UN-006 | Primary | General User | High | A resident monitors current temperature and humidity readings and sets target values so the home environment can be regulated to desired comfort conditions. |
| UN-007 | Primary | General User | High | A resident monitors door/window entry status and relies on alarms to detect potential security breaches in the home. |
| UN-008 | Primary | General User | Medium | A resident checks appliance power status and remotely changes appliance and lighting power states through programmable power switches. |
| UN-009 | Overarching | System Operators | Medium | Authorized parties require reliable communication between the web server, gateway, and home devices so monitoring and control commands can be exchanged across the home network. |
| UN-010 | Overarching | Administrators / System Operators | Medium | Authorized parties need the system to store home plans and data, maintain user accounts, and preserve backups of account information, plans, and the home database. |
