# Executive Summary Index: CAZ User Needs & System Requirements

## Project Overview
This package documents the end-to-end requirements engineering and interaction design for a Clean Air Zone (CAZ) user portal. The system enables users to understand CAZ schemes, check vehicle compliance, make payments, apply for exemptions, seek support, and manage refunds/PCNs, with a focus on fairness, accessibility, and minimal disruption.
