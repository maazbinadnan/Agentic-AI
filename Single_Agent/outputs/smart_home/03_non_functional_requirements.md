# 3. Non-Functional Requirements

### NFR-001  
- **Requirement:** The system shall provide a web interface that is responsive and usable on both desktop and mobile devices.
- **Source:** UN-001, UN-006

### NFR-002  
- **Requirement:** The system shall ensure that all user data and communications are protected using industry-standard security protocols.
- **Source:** UN-002, UN-006

### NFR-003  
- **Requirement:** The system shall provide simulated device responses within 2 seconds for 95% of user actions.
- **Source:** UN-001, UN-006

### NFR-004  
- **Requirement:** The system shall maintain data integrity and prevent data loss during backup and restore operations.
- **Source:** UN-005, UN-006

### NFR-005  
- **Requirement:** The system shall be designed to minimize operational costs by utilizing widely accepted and available technologies.
- **Source:** UN-006

### NFR-006  
- **Requirement:** The system shall support up to 5 concurrent users in the simulated environment without performance degradation.
- **Source:** UN-006
