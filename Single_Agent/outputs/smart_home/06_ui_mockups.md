# 6. UI Mockups and Interaction Design

See [07_ui_mockups_and_interaction_design.md](07_ui_mockups_and_interaction_design.md) for the full interaction design report and mapping table.

All HTML mockups are located in the `html/` subfolder and cover all required screen states (populated, empty, error/offline) for:
- Login
- Dashboard
- Security Alerts
- Configuration
- Backup & Restore
- Simulation

Each mockup is fully responsive and demonstrates the core user flows and error handling as specified in the requirements and user stories.
