# 1. High-Level User Needs

### UN-001: I need to securely access the DigitalHome system through a simple web interface.
- **User Group Type:** Overarching
- **User Group:** All Users
- **User Journey Context:** When a resident or technician wants to use DigitalHome, they must first access the system through a familiar web-based experience appropriate to their role.

### UN-002: I need to monitor the current environmental and device status of my home in one place.
- **User Group Type:** Primary
- **User Group:** General User
- **User Journey Context:** When a resident checks the home, they need to see current temperature, humidity, security sensor state, and appliance or lighting power status.

### UN-003: I need to control home environmental settings so the house remains comfortable.
- **User Group Type:** Primary
- **User Group:** General User
- **User Journey Context:** When room conditions change, the resident needs to review readings and adjust temperature and humidity set points through the web interface.

### UN-004: I need to monitor and respond to home security conditions.
- **User Group Type:** Primary
- **User Group:** General User
- **User Journey Context:** When doors or windows are monitored, the resident needs to know their state and whether alarms have been triggered so action can be taken.

### UN-005: I need to control power to appliances and lighting units remotely.
- **User Group Type:** Primary
- **User Group:** General User
- **User Journey Context:** When managing convenience, safety, or energy use, the resident needs to view current appliance states and switch them on or off remotely.

### UN-006: I need to configure system users and default settings for the household.
- **User Group Type:** Secondary
- **User Group:** Master User
- **User Journey Context:** When the household changes or defaults need updating, the designated Master User needs to manage accounts and system parameters.

### UN-007: I need to set up, maintain, and operate the DigitalHome system.
- **User Group Type:** Secondary
- **User Group:** DH Technician
- **User Journey Context:** During installation, maintenance, or troubleshooting, the technician needs advanced administrative control over configuration and operational state.

### UN-008: I need the system to preserve home plans, account data, and operational information reliably.
- **User Group Type:** Overarching
- **User Group:** All Users
- **User Journey Context:** While DigitalHome is in use, system data needs to be stored and backed up so the prototype can support continuous evaluation and recovery.
