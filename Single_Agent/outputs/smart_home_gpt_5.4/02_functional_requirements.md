# 2. Functional Requirements

### FR-001
- **Requirement:** The system shall provide a web-based authentication and session interface that allows authorized users to log in, log out, and access functions according to their assigned role.
- **Source Need:** UN-001, UN-006, UN-007

### FR-002
- **Requirement:** The system shall present a consolidated home status view showing current temperature readings, humidity readings, security sensor states, alarm states, appliance or lighting power states, and system connectivity status.
- **Source Need:** UN-002, UN-004, UN-005

### FR-003
- **Requirement:** The system shall allow authorized users to view thermostat readings and set or update thermostat temperature set points used to control heating and cooling behavior.
- **Source Need:** UN-003

### FR-004
- **Requirement:** The system shall allow authorized users to view humidistat readings and set or update humidity set points used to control humidifier and dehumidifier behavior.
- **Source Need:** UN-003

### FR-005
- **Requirement:** The system shall monitor magnetic contact switches and activate or display security alarm status when a monitored breach condition is detected.
- **Source Need:** UN-004

### FR-006
- **Requirement:** The system shall display the current state of each configured digital programmable power switch and allow authorized users to change the power state of the associated appliance or lighting unit.
- **Source Need:** UN-005

### FR-007
- **Requirement:** The system shall allow Master Users and DH Technicians to establish and maintain user accounts and update configurable default system parameters.
- **Source Need:** UN-006, UN-007

### FR-008
- **Requirement:** The system shall allow Master Users and DH Technicians to start, stop, and maintain the operational configuration of the DigitalHome system and its simulated devices through an administrative interface.
- **Source Need:** UN-007

### FR-009
- **Requirement:** The system shall store home plans, user account information, and home operational data on the DH home web server and shall provide backup support for that information.
- **Source Need:** UN-008, UN-006, UN-007
