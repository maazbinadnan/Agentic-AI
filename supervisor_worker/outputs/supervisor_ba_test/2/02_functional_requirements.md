# 2. Functional Requirements

### FR-001
- **Requirement:** The system shall provide users with current football news, live scores, and detailed team/player information for all national and international leagues and competitions.
- **Source Need:** UN-001
- **Priority:** High

### FR-002
- **Requirement:** The system shall allow users to select and manage their favorite teams and sports channels for personalized content display.
- **Source Need:** UN-002
- **Priority:** High

### FR-003
- **Requirement:** The system shall provide real-time notifications to users about news and live results for their selected favorite teams, and allow users to configure notification preferences by event type (e.g., goals, news, match start/end).
- **Source Need:** UN-003
- **Priority:** High

### FR-004
- **Requirement:** The system shall integrate live stream links from external providers (e.g., DAZN, Sky Sport) using deep links or embedded players, and display them only when transmission rights are fulfilled in the user's country. The system shall support provider authentication via OAuth and provider SSO. If authentication fails, the user shall receive a clear error message and be prompted to retry or cancel.
- **Source Need:** UN-004
- **Priority:** High

### FR-005
- **Requirement:** The system shall allow users to share news articles and match reports directly to Facebook, Twitter, WhatsApp, and Instagram, following each platform's sharing requirements.
- **Source Need:** UN-005
- **Priority:** Medium

### FR-006
- **Requirement:** The system shall provide a live ticker module that retrieves and displays live match data in real time via an external API.
- **Source Need:** UN-001
- **Priority:** High

### FR-007
- **Requirement:** The system shall allow users to register and log in directly at app startup using email/password, phone number (with SMS verification), and social login (Google, Apple, Facebook).
- **Source Need:** UN-002
- **Priority:** High

### FR-008
- **Requirement:** The system shall allow users to personalize the app interface by configuring modules (add/remove), selecting from at least three themes (e.g., light, dark, team colors), and arranging up to five widgets (e.g., live scores, news, upcoming matches, favorite team stats, notifications). Integration of external APIs or custom code is not supported.
- **Source Need:** UN-011
- **Priority:** Medium
