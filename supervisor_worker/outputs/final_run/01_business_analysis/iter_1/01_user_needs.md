# 1. High-Level User Needs

### UN-001: I need to access football news, live scores, and team/player information quickly and reliably so that I can stay informed about my favorite teams and competitions.
- **User Group Type:** Primary
- **User Group:** Football Fan
- **Demand Level:** High
- **User Journey Context:** User opens the app, selects favorite teams, and browses news, live scores, and team/player details.

### UN-002: I want to personalize my app experience by selecting favorite teams and sports channels so that I only see relevant news and results.
- **User Group Type:** Primary
- **User Group:** Football Fan
- **Demand Level:** High
- **User Journey Context:** User configures preferences during onboarding or in settings to filter content.

### UN-003: I want to receive real-time notifications about news and live results for my favorite teams so that I never miss important updates.
- **User Group Type:** Primary
- **User Group:** Football Fan
- **Demand Level:** High
- **User Journey Context:** User enables notifications and receives push alerts for selected teams and events.

### UN-004: I want to watch live streams of football matches when available and permitted in my country so that I can follow games directly from the app.
- **User Group Type:** Primary
- **User Group:** Football Fan
- **Demand Level:** High
- **User Journey Context:** User accesses live stream links for matches, with access controlled by transmission rights.

### UN-005: I want to share football news and match reports with friends via social media so that I can engage with my community.
- **User Group Type:** Primary
- **User Group:** Football Fan
- **Demand Level:** Medium
- **User Journey Context:** User reads news or reports and uses share functionality to post to social media.

### UN-006: I need the app to load and be ready to use within two seconds so that I can access information without delay.
- **User Group Type:** Overarching
- **User Group:** All Users
- **Demand Level:** High
- **User Journey Context:** User launches the app and expects immediate access to main features.

### UN-007: I need the app to function reliably even with limited network coverage or temporary offline conditions so that I can continue using the app without interruption.
- **User Group Type:** Overarching
- **User Group:** All Users
- **Demand Level:** High
- **User Journey Context:** User accesses the app in areas with poor connectivity or during network outages.

### UN-008: I need my personal data to be protected and processed in compliance with GDPR so that my privacy is ensured.
- **User Group Type:** Overarching
- **User Group:** All Users
- **Demand Level:** High
- **User Journey Context:** User registers, logs in, and uses the app, expecting data protection.

### UN-009: I need the app to support up to 100,000 simultaneous users without performance loss so that I can use the app even during peak times.
- **User Group Type:** Overarching
- **User Group:** All Users
- **Demand Level:** High
- **User Journey Context:** User accesses the app during high-traffic events such as match days.

### UN-010: I want the app to be available on both Android and iOS devices so that I can use it regardless of my mobile platform.
- **User Group Type:** Overarching
- **User Group:** All Users
- **Demand Level:** High
- **User Journey Context:** User downloads and installs the app from the respective app store.

### UN-011: I need to ensure the app is thoroughly tested and user feedback is evaluated so that malfunctions are detected early and functionality is continuously improved.
- **User Group Type:** Secondary
- **User Group:** Product Owner
- **Demand Level:** High
- **User Journey Context:** Product owner reviews test results and user feedback to plan improvements.
