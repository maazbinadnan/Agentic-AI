# 3. Non-Functional Requirements

### NFR-001
- **Requirement:** The system shall load and be fully ready for user interaction within two seconds after startup on both Android and iOS devices.
- **Source:** UN-001, UN-002
- **Priority:** High

### NFR-002
- **Requirement:** The system shall support up to 100,000 concurrent users without performance degradation during peak usage periods.
- **Source:** UN-003, UN-004
- **Priority:** High

### NFR-003
- **Requirement:** The system shall remain usable offline, allowing access to previously loaded content and core features, if the network connection is temporarily lost.
- **Source:** UN-005, UN-006
- **Priority:** High

### NFR-004
- **Requirement:** The system shall process all personal data in compliance with the General Data Protection Regulation (GDPR).
- **Source:** UN-007
- **Priority:** High

### NFR-005
- **Requirement:** The system shall only display live stream links when transmission rights are fulfilled in the user’s country.
- **Source:** UN-008
- **Priority:** High

### NFR-006
- **Requirement:** The system shall allow registration and login to be completed within 30 seconds under normal network conditions.
- **Source:** UN-009
- **Priority:** Medium

### NFR-007
- **Requirement:** The system shall provide a user interface that enables direct access to all modules and information within two navigation steps.
- **Source:** UN-010
- **Priority:** High

### NFR-008
- **Requirement:** The system shall be available for download and installation on both Android and iOS platforms.
- **Source:** UN-011
- **Priority:** High

### NFR-009
- **Requirement:** The system shall undergo comprehensive system and user acceptance testing prior to release, with all critical defects resolved.
- **Source:** UN-012
- **Priority:** Medium

### NFR-010
- **Requirement:** The system shall enable users to share news and game reports via social media platforms directly from the app.
- **Source:** UN-013
- **Priority:** Medium

### NFR-011
- **Requirement:** The system shall ensure that all modules and the user interface remain consistent and operational during external server updates.
- **Source:** UN-014
- **Priority:** High

### NFR-012
- **Requirement:** The system shall update live ticker data and display current match information within one second of receiving new data from the external API.
- **Source:** UN-015
- **Priority:** High

### NFR-013
- **Requirement:** The system shall provide a notification system that delivers event alerts to users within five seconds of the event trigger.
- **Source:** UN-016
- **Priority:** High

### NFR-014
- **Requirement:** The system shall continuously evaluate user feedback and app reviews to identify and implement improvements within quarterly release cycles.
- **Source:** UN-017
- **Priority:** Medium
