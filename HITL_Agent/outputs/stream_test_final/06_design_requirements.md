# Visual & UI Design Requirements Specification

## 1. Executive Summary & Design Vision
- **Product Aesthetic Tone**: Clean Minimalist (Bento UI inspired)
- **Target Experience**: Mobile-first football app for Android & iOS, fast-loading, real-time updates, personalized content

## 2. Color Theme & Palette
- **Mode Preference**: Supports both Light and Dark Mode
- **Primary Color**: #0E2804 (Brand Green)
- **Secondary / Accent Colors**: [Default Assumption] To complement the brand green, use #3B82F6 (Blue) and #F59E42 (Orange) for highlights and notifications
- **Background & Surface**: [Default Assumption] Light Mode: #F9FAFB (Background), #FFFFFF (Surface); Dark Mode: #181A1B (Background), #23272A (Surface)

## 3. Typography & Hierarchy
- **Primary Font Family**: Roboto (Modern sans-serif)
- **Heading Hierarchy**:
  - H1: 2rem (32px), Bold
  - H2: 1.5rem (24px), Semi-bold
  - Body: 1rem (16px), Regular

## 4. Layout & UI Structure
- **Navigation Style**: Side Drawer (Mobile drawer navigation)
- **Density**: [Default Assumption] Spacious, with clear separation between modules and cards
- **Card & Container Style**: Rounded corners (12px), subtle shadow, clean minimal surfaces (Bento UI style)

## 6. Documented Default Assumptions
- Secondary/accent colors chosen to complement brand green and support notification/highlight needs.
- Background and surface colors selected for optimal readability and accessibility in both modes.
- Spacious layout assumed for clarity and ease of use on mobile devices.
- Card/container style follows Bento UI principles with rounded corners and subtle shadow.
