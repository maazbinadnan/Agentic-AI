# 1. High-Level User Needs

### UN-001: Monitor the home environment and device states through a simple web interface
- **User Group Type:** Primary
- **User Group:** General User
- **Demand Level:** High
- **User Journey Context:** During routine home checking, the user logs in via a personal web page to view current temperature, humidity, security sensor status, and appliance or lighting power states without needing technical knowledge beyond basic web use.

### UN-002: Remotely control environmental conditions and appliance power in the home
- **User Group Type:** Primary
- **User Group:** General User
- **Demand Level:** High
- **User Journey Context:** After reviewing current home conditions, the user adjusts thermostat and humidistat set points and changes the on/off state of supported small appliances or lighting units to manage comfort and energy usage.

### UN-003: Use planning and scheduling features to manage recurring home behavior
- **User Group Type:** Primary
- **User Group:** General User
- **Demand Level:** High
- **User Journey Context:** When organizing daily and longer-term household routines, the user creates or updates daily presets and monthly plans so the system can support predictable environmental and power-management behavior.

### UN-004: Review historical performance and event information to understand home patterns
- **User Group Type:** Primary
- **User Group:** General User
- **Demand Level:** Medium
- **User Journey Context:** After the system has collected data over time, the user accesses historical reports such as averages, minimums, maximums, and downtime logs to assess past environmental conditions and system behavior.

### UN-005: Access the system securely with personal account credentials
- **User Group Type:** Overarching
- **User Group:** All Authenticated Users
- **Demand Level:** High
- **User Journey Context:** Before using any DigitalHome capability, the user signs in with a username and password and uses basic web actions such as logging in, browsing pages, submitting requests, and logging out.

### UN-006: Configure system parameters and maintain user accounts for the household
- **User Group Type:** Secondary
- **User Group:** Master User
- **Demand Level:** High
- **User Journey Context:** When household administration is needed, the designated master user changes default parameter settings and adds or maintains user accounts so the home system remains usable for residents.

### UN-007: Set up, maintain, and reconfigure the DigitalHome system during installation and support
- **User Group Type:** Secondary
- **User Group:** DH Technician
- **Demand Level:** High
- **User Journey Context:** During system deployment or maintenance, the technician sets up the DigitalHome configuration, adjusts system parameters, establishes user accounts, and maintains the operational setup using specialist product knowledge.

### UN-008: Start and stop DigitalHome system operation when required for maintenance or control
- **User Group Type:** Secondary
- **User Group:** DH Technician / Master User
- **Demand Level:** Medium
- **User Journey Context:** During maintenance, troubleshooting, or configuration changes, the authorized administrator or technician needs to control when the DigitalHome system is running or stopped.

### UN-009: Rely on stored plans, data, and backups to preserve household configuration and usage information
- **User Group Type:** Overarching
- **User Group:** All Authenticated Users
- **Demand Level:** Medium
- **User Journey Context:** As the system is used over time, users depend on the home web server to retain user plans, account information, and home data, with backup support to reduce loss of configured information.
